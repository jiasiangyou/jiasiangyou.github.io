# 手指點讀圖鑑（數位版）— 分析與規劃

## 1. 實體點讀書在做什麼

拆開來看，一本實體點讀書（例如「FOOD 超人 手指點讀生活圖鑑」）有四個部分：

| 實體書的功能 | 說明 | 數位版做法 |
|---|---|---|
| 圖像場景 | 一頁一個主題，例如街道、公園、消防局 | 場景圖加上可點的熱區（百分比座標） |
| 點讀發音 | 按一下就唸出單字或句子 | Web Speech API（不需要錄音檔）。之後可以換成真人錄音 mp3 |
| 雙語 | 中文和英文 | 語言切換：中 / 中英 / EN |
| 問答模式 | 書上寫的「222 問問答」 | 問答模式：題目用語音唸，小朋友點答案，答對有星星和動畫 |

實體書會壞，多半是電池、按鍵或喇叭的問題。iPad 版沒有這些零件，內容也可以一直加。

## 2. 依年齡分級的設計

| | 1–2 歲（寶寶認知） | 3–4 歲（生活場景） | 5–6 歲（挑戰問答） |
|---|---|---|---|
| 畫面 | 格狀排列，一頁 6 個大圖，觸控範圍很大 | 完整場景，物件散布在畫面上 | 完整場景 |
| 內容 | 動物、水果、交通工具 | 街道、公園、廚房、動物 | 街道、公園、廚房、居家安全 |
| 點讀 | 唸名稱，加上狀聲詞（汪汪） | 唸一個短句，可以切中英文 | 唸短句；英文模式會拼字（F, I, R, E…） |
| 問答 | 「狗狗在哪裡？」 | 「消防車在哪裡？」 | 用描述來問：「哪一台車會噴水救火？」 |
| 預設模式 | 點讀 | 點讀 | 問答 |
| 答錯 | 溫和提示：「再找找看」 | 同左 | 答錯第二次時，正確答案會跳一下當提示 |

設計原則：

- **零失敗感**：答錯不扣分，只是沒有星星。也沒有計時。
- **觸控目標大**：熱區至少 60px，按鈕至少 64px，適合幼兒手指。
- **防誤觸**：家長設定要長按 ⚙️ 1.2 秒才會打開。也停用了 iOS 的雙擊放大和雙指縮放。
- **立即回饋**：點下去就有動畫、語音和文字泡泡。用 `pointerdown` 觸發，不用等手指放開。

## 3. 技術架構

```
touch-book/
├── index.html      # 目前的 prototype（單檔、無相依、可離線）
└── PLAN.md
```

**Prototype 階段（現在）**：純 HTML、CSS、JS 單檔。圖用 emoji，語音用瀏覽器內建 TTS。GitHub Pages 可以直接部署。

**正式版建議**：

1. **內容資料化**：把 `BOOKS`、`AGES` 抽成 `content/*.json`。每頁的格式如下：
   ```json
   { "title": "街道", "type": "scene", "bg": "street.webp",
     "items": [{ "id": "firetruck", "img": "firetruck.webp", "zh": "消防車", "en": "fire truck",
                 "say": "消防車要去救火！", "q": "哪一台車會噴水救火？",
                 "audio": { "zh": "firetruck.zh.mp3", "en": "firetruck.en.mp3" },
                 "x": 20, "y": 75, "s": 13 }] }
   ```
2. **圖片**：emoji 在各平台長得不一樣，正式版建議改用統一風格的插圖（SVG 或 WebP）。來源可以是 AI 生成後再修圖、免費素材（例如 OpenMoji、unDraw），或自己畫。
3. **語音**：iPad 的 TTS 中文聲音（美佳）堪用，但比較機械。可以先在播放程式裡加上「有 mp3 就播 mp3，沒有就用 TTS」的退路，再逐步改成真人錄音（例如爸媽自己錄）。
4. **離線 / PWA**：加上 `manifest.json` 和 Service Worker 快取所有素材。iPad 用 Safari 的「加入主畫面」後就能全螢幕、離線使用。
5. **框架**：內容量變大以後，可以改用 Vite + Vue 或 React。目前單檔已經夠用。
6. **編輯器（選做）**：做一個家長用的頁面，上傳場景圖後拖曳熱區、填中英文字，直接產生 JSON。這樣以後加新書不用改程式。
7. **紀錄（選做）**：用 localStorage 記住每個主題的星星數，給家長看學習進度。

## 5. 在 iPad 上使用

1. 用 Safari 打開 `https://jiasiangyou.github.io/touch-book/`（分支合併到 GitHub Pages 的發布分支後才會生效）。
2. 按「分享」→「加入主畫面」，之後會像 App 一樣全螢幕開啟。
3. 建議開啟「引導使用模式」（設定 → 輔助使用 → 引導使用模式），小朋友就跳不出這個 App。
4. 如果沒有聲音，請確認 iPad 側邊的靜音開關，並在「設定 → 輔助使用 → 朗讀內容 → 聲音」下載中文（台灣）的語音。
